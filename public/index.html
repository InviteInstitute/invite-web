Learner Modeling Dashboard

In real time, surfaces which students need help in VEXcode VR. It flags students who are wheel-spinning, inactive or working step by step, and lists them in a Needs Intervention column.

Live at dashboard.inviteai.org

INVITE Agent

The chat agent and the pedagogical agent in one. It chats with students as they code in VEXcode VR and ZANY, checks in when they’re stuck, and talks them through it out loud as a 3D pedagogical agent.

Live at agent.inviteai.org

Pedagogical Agent Toolkit

Tools for pedagogical agent design and testing. Its agent creator builds a 3D agent’s face, body, hair, eyes, outfit, accessories and shoes.

Live at patk.inviteai.org. It asks for a password.
