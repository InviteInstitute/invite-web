# Surface: inviteai.org tools index (public/index.html)

Mode: Operate (primary: insiders launching a tool) with a Read layer for evaluators.
Job: reach the right tool in one click; understand what exists and what is live.
Constraints: static HTML/CSS, self-hosted assets, header carries only the logo plus its own two-item nav, PA Toolkit password prompt stays.
Pinned world: invite.illinois.edu (TheGem). Structure dictated by that site's inner-page template; no concept roll (pinned brief, whole surface inside an established world).

## Direction contract

THESIS: A page from the institute's own site that happens to be the software index. It refuses the SaaS card grid (rounded tiles, pill badges, shadows) in favor of TheGem's square, ruled, uppercase-Montserrat document grammar.

OWN-WORLD: White ground, #3c3950 uppercase Montserrat 700 headings with tracking, #5f727f Source Sans body, light 300 lead paragraph, 1px #dfe5e8 rules, square corners, #00bcd4 accent as rules/tabs/button borders, #e7ff89 lime as the "live" signal, dark lined title-texture bar with the 18px cyan tab, #1c3947 footer with Montserrat UltraLight headings and the partner logo wall.

STORY: Visitor sees the INVITE header and title bar and knows they are still at INVITE; reads one light lead line saying what this is; moves down three photo-paired rows, each an institute classroom photo (torn edges, hex overlay, from the homepage carousel) beside the tool's status, description, address and outlined launch button; evaluators find source code and institute links in the gray band below; footer carries funding and partners.

FIRST VIEWPORT: 91px white header (logo left, "Research Software" boxed-active + "INVITE Institute" right). Title bar 83px, "RESEARCH SOFTWARE" right-aligned 36/53, title hung 62px off the viewport edge, 18px cyan tab flush right. Lead paragraph 24/37 light across the container. First row at 1440x900: photo left half, Learner Modeling Dashboard title, Live chip and launch button right half, above the fold. Rows alternate photo side; on phones photos go full-bleed above each tool.

FORM: TheGem page grammar in photo-paired rows, chosen by the user from three layouts (homepage-style, photo-paired rows, compact launch pad) after rejecting the single-column-plus-sidebar build. World pinned by the user: "I want to have the same design elements in my website inviteai.org". No seed key: concept-seed not run because the user pinned the world and picked the structure.

Signature interaction: launch buttons fill cyan from the left on hover and focus, with the arrow nudging; nothing else moves.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
